## 📌 為什麼需要這份指南？

每逢高三升學季，澳門許多應屆生與家長手握**學界競賽獎項、校際辯論隊正選、體育校隊、義工時數或雅思/托福證書**，卻常常因為資訊分散在各大學幾十份 PDF 與招生章程中，而**錯失了換取高達 20 至 50 分入學筆試加分、免考關鍵科目、或校長推薦保送全額免學費獎學金的黃金機會**！

更有甚者，許多家長誤以為「加分等考完聯考再補交就好」，殊不知**每年 1 月報名入學考試當下就必須同步申報並上傳比賽章程**，逾期徹底失效！

本專案旨在客觀、權威、清晰地梳理澳門所有高等院校（公立與私立）的加分與優惠體系，並提供**即時互動試算匹配器**與**升學防踩坑攻略**。

## 💡 家長與畢業生必讀 5 大核心觀念

1. **四校聯考不是「聯考統招」**：
   - 四校聯考只負責聯合考試出題，**四所學校獨立錄取、各看各的加分、發各自的通知書**！欲報讀必須分別在 1 月份登入各校網上報名系統獨立申請。
2. **「加分計劃」致命時效在 1 月**：
   - 加分必須在**報名四校聯考當月（1月）**上載獲獎證書、比賽章程及獲獎名冊。考完聯考後才拿出來**完全不予受理**！
3. **加分具有極高性價比**：
   - 澳大單科加 20-50 分，跨類別疊加後能顯著拉開競爭差距，是爭取法學、計算機、商科等熱門專業的關鍵護城河。
4. **考試豁免 ≠ 加分計劃**：
   - 雅思/托福或奧數二等獎以上可直接申請**豁免考試（不用坐考場考該科）**；加分計劃則是去考試後在成績上疊加。兩者可同時配合使用！
5. **保送與聯考雙保險策略**：
   - 9-11月若保送已獲正取心儀專業，恭喜提前上岸；若保送專業不理想，1月果斷報名四校聯考並同步啟用加分計劃，實現二次衝刺！

